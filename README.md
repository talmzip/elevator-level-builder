# Elevator Level Builder

A mobile-first web tool for designing, playtesting and storing levels for the elevator sliding-block puzzle (Meta VR Start 2026 entry). Place rigid, accordion, twin and turner creatures around the kid, test the level in Play mode, and export every level as the JSON the Unity game imports. Plain HTML / CSS / ES modules with no build step; levels auto-save to the browser's `localStorage`.

Live: https://talmzip.github.io/elevator-level-builder/
